# 🎤 МузСтудия

Мини-студия в кармане: запиши свой голос или любой звук с микрофона и собери из записей трек на пяти дорожках — прямо в браузере телефона или компьютера. Один HTML-файл, без установки, без регистрации, без сервера.

## Возможности

- **Запись с микрофона** — до 30 секунд, с живой осциллограммой и отсчётом «4-3-2-1» со щелчками метронома перед началом
- **5 дорожек** с цветными блоками: Голос, Мелодия, Окружение, Ритм, Басы
- **Перетаскивание как в DAW** — тяни блок пальцем: у края экрана лента сама прокручивается, блок прилипает к краям других блоков, плейхеду и долям метронома; наложений не бывает — блок встаёт к ближайшему свободному месту
- **Обрезка блоков** — белые риски по краям блока: тяни, чтобы растянуть или сжать (обрезать начало или конец)
- **Тон ±12 полутонов** и громкость каждого блока (блок можно и замедлить, и ускорить)
- **Двойной тап — мгновенная копия** блока со всеми настройками
- **Метроном** 40–240 BPM с прилипанием блоков к долям
- **Плейхед-скраб** — тащи линейку времени, чтобы перемотать; во время воспроизведения играющий блок подсвечивается
- **Тёмная и светлая темы**

## Как запустить

**Вариант 1 — просто открыть файл.** Скачай `index.html` и открой его двойным кликом — всё работает локально.

**Вариант 2 — GitHub Pages.** В настройках репозитория: *Settings → Pages → Deploy from branch → main → / (root)*. Страница будет доступна по адресу `https://<имя-пользователя>.github.io/music-studio/`.

> Браузер спросит доступ к микрофону при первой записи — нажми «Разрешить». Для `file://` записи микрофон работает в Chrome и Edge; для гарантированной работы на телефоне удобнее открыть страницу по HTTPS (GitHub Pages это даёт автоматически).

## Технологии

Один самодостаточный файл `index.html` (~50 КБ): чистый JavaScript без фреймворков и зависимостей.

- [Web Audio API](https://developer.mozilla.org/ru/docs/Web/API/Web_Audio_API) — воспроизведение, микширование, метроном, изменение тона через `playbackRate`
- [MediaRecorder API](https://developer.mozilla.org/ru/docs/Web/API/MediaRecorder) — запись с микрофона
- Canvas — отрисовка волновых форм
- Pointer Events — перетаскивание и обрезка блоков на тач-экранах и мышью
- localStorage — хранение настроек

Проект (записи и раскладка блоков) живёт в памяти вкладки до перезагрузки страницы.

## Совместимость

Chrome, Edge, Safari, Firefox — актуальные версии, десктоп и мобильные. Запись звука требует HTTPS (или `localhost`).
